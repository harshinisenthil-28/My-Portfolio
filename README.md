# Harshini S - Personal Portfolio

A modern, responsive, highly interactive personal portfolio website built with **React** and **Vite**, based on the design theme and masonry structure of [giresh.tech](https://giresh.tech/).

---

## 🎨 Design Theme & Features
- **Color Palette**: Terracotta primary accent (`#c1694f`), warm gold (`#e9c46a`), warm sand (`#d4a373`), soft lavender (`#9b8baf`), sage green (`#6b9080`), and light beige background (`#f0ebe3`).
- **Typography**: `Playfair Display` for headings and titles; `DM Sans` for body copy.
- **Masonry Grid**: Pinterest-style column layout with card pins for Who I Am, Education, Tech Stack, Experience, Achievements, and Projects.
- **React Innovations**:
  - 🤖 **Interactive AI Cyberbullying Detector Simulation**: Test sample text against Gemini AI sentiment classification inside the project modal.
  - 📱 **QR Smart Queue Token Simulator**: Generate an instant queue token and view real-time estimated wait time countdown.
  - 🏷️ **Categorized Tech Stack Filter**: Interactive buttons to filter skills by Languages, Backend, Frontend, and Databases/Tools.
  - 📱 **Responsive Design & Mobile Drawer**: Seamless layout on desktop, tablet, and mobile.

---

## 🚀 How to Run

### 1. Install Dependencies
```bash
cmd /c npm install
```

### 2. Start Development Server
```bash
cmd /c npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Build for Production
```bash
cmd /c npm run build
```
The optimized production build will be generated in the `dist/` directory, ready to deploy to Vercel, Netlify, or Render.
